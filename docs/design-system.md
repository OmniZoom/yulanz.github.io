# Design System

The visual direction is minimal editorial research plus AI product case study. Desktop
uses a narrow sticky left rail for identity and content tabs. Mobile converts the rail to
a compact header with horizontally scrollable tabs.

The palette uses warm paper, deep ink, and a single green accent. Display typography uses
English display typography uses the self-hosted Newsreader variable font and interface/body typography uses the self-hosted Inter variable font. Chinese text uses explicit system fallbacks (Songti SC/STSong for display and Noto Sans CJK SC/Microsoft YaHei for interface text), avoiding a third-party font request.
