# Content Strategy

The portfolio separates measured evidence, product hypotheses, retrospective analysis,
and known limitations. It must not invent user research, employment, publications,
metrics, business impact, or cost.

The homepage is a concise professional index. Long-form evidence belongs in project case
studies. English is canonical; Chinese is maintained as an intentional translation rather
than browser-generated text.

## Project video

Project video is optional and must not leave an empty player when no recording is supplied.
The preferred delivery is a public or unlisted YouTube/Bilibili video with reviewed captions
and a local poster image. The site should load the third-party player only after the visitor
chooses to play, which keeps the initial static page fast and limits unnecessary third-party
requests.

For a self-hosted alternative, use a compressed H.264/AAC MP4, a WebVTT caption track, and a
poster image. Avoid committing a large source recording to the Git repository; publish it as
a release asset or through a dedicated media host instead.
